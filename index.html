Cómo se usa

  1. Elija un ejemplo o abra un archivo .json con Abrir….
  2. Arrastre los nodos del grafo; toque uno para ver su tabla de probabilidad condicional.
  3. En Consulta, marque una o más variables de consulta y/o elija el estado de las variables de evidencia.
  4. Pulse Ejecutar eliminación de variables. Verá las distribuciones, P(evidencia), el orden de eliminación y cada paso.
  5. Guardar descarga la red (con la posición de los nodos). Imprimir imprime el reporte de la red y del último resultado.
  6. Para crear o modificar una red use el editor JSON; se valida (DAG, filas de CPT que suman 1, 3 a 10 nodos).
